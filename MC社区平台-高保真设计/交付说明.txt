MC HUB · Minecraft 应用与社区交流平台
高保真设计交付说明 V1.0
================================================================

一、交付内容
1. MC社区平台-高保真原型.xd
   41 个画板，覆盖信息架构 V1.0 全部页面（L1×1 / L2×5 / L3×18 / L4×13 / L5×1 / 全局×3）。
   画板之间已写入完整交互连线（1,410 条），触发方式为「点击 / 溶解过渡 0.3s」。
   打开方式：Adobe XD → 文件 → 打开 → 选择该 .xd；进入「原型」模式即可点击预览。

2. 高保真网页预览/
   直接双击 index.html 打开目录页，选择任意页面进入可点击原型。
   页面内顶部导航、面包屑、卡片、页脚、按钮均可点击跳转；右下角可切换上一页 / 下一页 / 返回目录。
   41 个页面为独立 HTML，内联 SVG，无需服务器即可浏览。

3. SVG源文件/
   41 张高保真画板源文件（1920 宽），可直接导入 Figma / Illustrator / Sketch 继续编辑。

4. 预览图/
   8 张关键页面 1:1 预览 PNG（首页、频道页、详情页、列表页、论坛、播放页、表单、登录）。

二、设计系统（依据《UI设计知识库_三书精读》）
· 画布：1920×可变高度；安全宽 1200；左右留白 360；12 列栅格（70 列宽 + 30 沟槽）。
· 字体：中文 微软雅黑 / Noto Sans CJK SC；等宽 Consolas。正文 14px，行高 26px；标题 20–44px。
· 色彩：主题绿 #6EA832 / 亮绿 #93C94A / 深绿 #4A781B；墨黑 #0C130D；纸白 #F4F5EE；
        辅助琥珀 #D9A13B、蓝 #3D7FA6、粉 #C4699A；描边 #D7DEC9。
· 布局：标题区高度 214/246/250 三档；卡片间距 24；区块间距 56–80；页脚四列兜底。
· 视觉语言：方块像素（voxel scene / pixel icon / 2px 描边 / 直角卡片 / 等宽索引编号），
            不使用照片素材，所有插画由几何方块生成，保证 SVG 与 XD 完全一致。

三、信息架构落点
· 6 条导通规则全部实现：全局导航常驻（R1）、面包屑回溯（R2）、列表→详情（R3）、
  跨频道相关推荐（R4）、下载链路强关联（R5）、页脚兜底 + 全局搜索（R6）。
· 关键路径：首页 → 认识 MC → 游戏简介 → 版本与玩法 → 教程 → 启动器；
           首页 → 下载中心 → MOD → 前置 MOD → 整合包 → 启动器；
           首页 → 社区 → 论坛 → 板块 → 帖子（L5）→ 登录 → 个人中心。
· 原低保证 XD 中的部分连线已由本版完整连线替代，覆盖面从 40 个画板扩展到 41 个
  （补入缺失的 P030301 我的内容）。

四、说明
· 本高保真工程采用纯矢量构建（矩形 / 文本），以保证在 Adobe XD 中原样打开且可继续编辑；
  未使用位图素材，因此不存在丢失图片链接的问题。
· 若需修改品牌色，请在 SVG 生成脚本（hifi/ds.py）中调整色板后重新生成，可保持全站一致。

五、保存到本机桌面
· 当前生成环境为远程沙箱，无法直接写入你电脑的桌面路径。
· 请下载压缩包 MC社区平台-高保真设计_V1.0.zip，解压后整个文件夹拖到桌面即可。
